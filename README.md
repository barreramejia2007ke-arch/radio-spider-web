# Radio Spider Web

Página web informativa de ejemplo para una emisora estudiantil. Este repositorio se creó con fines educativos para practicar desarrollo web y control de versiones con Git y GitHub.

## Contenido
- Página de inicio.
- Información sobre Radio Spider.
- Ejemplos de espacios de programación.
- Novedades de la emisora.
- Sección de contacto.
- Menú adaptable para dispositivos móviles.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Estructura del proyecto
```text
radio-spider-web/
├── index.html
├── css/
│   └── estilos.css
├── js/
│   └── script.js
├── img/
│   └── logo-radio-spider.png
└── README.md
```

## Cómo ejecutar
1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Abre `index.html` en un navegador web.

No requiere instalación de dependencias ni servidor para esta versión inicial.

## Crear y subir el repositorio con Git
Después de crear un repositorio vacío en GitHub, abre una terminal dentro de esta carpeta y ejecuta:

```bash
git init
git add .
git commit -m "Crear sitio inicial de Radio Spider"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/radio-spider-web.git
git push -u origin main
```

Reemplaza `TU-USUARIO` por tu usuario real de GitHub y utiliza la dirección que GitHub proporcione para tu repositorio.

## Ejemplo de mejora y segundo commit
Después de modificar algún archivo, por ejemplo `index.html`, ejecuta:

```bash
git status
git add index.html
git commit -m "Actualizar contenido de la página"
git push
```

## Estado del proyecto
Versión inicial de demostración. Los horarios, noticias, transmisión en vivo y datos de contacto reales deben agregarse cuando estén confirmados.
